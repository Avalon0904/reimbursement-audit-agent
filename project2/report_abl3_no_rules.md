## 二、预测复盘（事前写死，赛后认账）

三个预测（常规~94 / 对抗70~78 / 成本70~80%）**全部落空，且方向一致**：低估了 LLM 的"不愿负责"。
预测假设 judge 拿到条款原文会照判；实际它把边界决策外包回给人——A03 条款引用完全正确（2.1）仍选择转人工，
证明这不是检索或理解问题，是**承诺问题**（commitment problem）。

## 三、误差分解（15 单错，三类病根）

| 病根 | 数量 | 单据 | 机制 |
|---|---|---|---|
| **胆小类** | 12 | A01-A03、B01-B02、E03-E04、R40（不敢驳回/抢先短路）；R00、R02、R15、R43（误转） | 判词清一色"按4.1转人工复核，不擅自通过或驳回" |
| **检索漏** | 2 | R04、R34（真值 2.3 打车超限） | BM25 top-4 无 2.3（实测 top4=1.4/4.1/1.5/2.1）：口语"打车费"vs制度语"交通费"，v0.4 词面重叠盲区复现；judge 无条款可用只能 pass |
| **幻觉违规** | 1 | R16（pass→reject，凭空引用 2.1） | 确定性 if 永远不会"幻觉一个违规"，LLM 会 |

**胆小类的结构放大器**：judge 占据审核链最前位，它一说 review，单子直接进人工门，
**下游 verify/ledger 的确定性证据根本没机会产生**——B02 的连号、E03/E04 的金额不符，②里都是下游工具稳抓的，
③里被 judge 的"存疑"提前截流。转人工不是免费兜底，它短路了证据链。

## 四、三条教训（比分数值钱）

1. **"能确定性判的绝不让 LLM 判"获得定量反面实证**：LLM 拿对条款也不愿为边界决策负责（A03 铁证），
   且会幻觉违规（R16）——规则层 0 token、100% 可复现、永不错乱的价值，用 40pp 对抗分换回来的认知。
2. **节点顺序即架构**：确定性工具应前置积累证据，LLM 判断应后置消费证据；③把顺序反过来，
   证据链被"存疑"截流。这解释了为什么②的流水线是 rule_check → verify → ledger 而非 LLM 先行。
3. **检索质量进入系统关键路径**：②里检索只做驳回引用（挂错不致命），③里检索漏 = 判断无依据 = 漏判（R04/R34）。
   同义词扩展之外的 BM25 盲区（类目别名）若上生产需向量腿兜底——项目一混合检索的结论在项目二复现。

口径注记：③的 judge prompt 一版封板未调优（变量唯一纪律）；prompt 施压（"必须拍板"）可回升胆小类分数，
但不改变幻觉违规与短路两个结构性结论。模糊分层对 k3 无挑战的观察项维持（blur 层 86.7 的误差同样全是胆小类）。
